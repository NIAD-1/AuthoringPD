# Self-Authoring Suite & Wall Card Studio (Offline Edition)

### 🚀 How to Open Offline:
1. **Option A (Double-Click)**: Simply double-click **`start.command`** in this folder.
2. **Option B (Terminal)**:
   ```bash
   npm run dev
   ```
   Then open: **http://localhost:3000** in your browser.

### 🔒 100% Offline & Local Data:
- You can disconnect your Wi-Fi completely.
- All answers, goals, and traits are saved in **LocalDB (IndexedDB & LocalStorage)** on your machine.
- Print cards anytime via the **Wall Cards Studio** tab!
